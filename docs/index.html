FaceAnchor — verify it yourself

Nothing to install. Everything below runs in this tab.

FaceAnchor writes a face-match record to a public blockchain, and the contract refuses to store one unless a zero-knowledge proof shows the similarity is real. That is a strong claim, so here is the evidence rather than the assertion.

This page fetches the published evidence straight from the GitHub repo, verifies the Groth16 proof in your browser, and reads the record back off Base Sepolia. It uses no server of ours — only raw.githubusercontent.com and a public RPC.

What this does not show. The proof binds the published similarity to two committed face embeddings, and the post-side embedding to the published image. It does not prove the scanned embedding came from the scanned photograph — that needs the face model itself inside the circuit, which is far beyond what any laptop can prove. The full accounting is in what-is-proven.md.
